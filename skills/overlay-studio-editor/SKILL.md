# 使用剪辑中台制作视频

先定位实际工作台根目录（包含package.json、scripts/studio-cli.mjs、templates/）；不要假定作者电脑路径或固定端口。本技能可直接读取，不依赖自动安装识别；平台支持技能导入时可导入本文件夹。不要修改WorkBuddy自身配置来强制注册。

必读：[剪辑制作规范](references/剪辑制作规范.md)。随后读取当前工作台的templates/team-rules.json与templates/README.md，再按需读取选定模板的控制文件。明确用户要求优先；长期偏好与单片要求分别记录。

## 首次使用与用户标准（先执行）

先运行 `node scripts/preferences.mjs status`。needsChoice 为 true 时，必须询问“采用默认剪辑标准，还是建立自己的标准？”等待用户选择，不把未回复当作默认同意。默认值见命令输出，包括字体、字幕、BGM、音效、响度和原速。

用户明确选择默认后运行 `node scripts/preferences.mjs defaults`；自定则协助填写标准 JSON，并运行 `node scripts/preferences.mjs custom 标准.json`。CLI与网页共享 user-data/preferences.json；后续读取并沿用，不重复询问。用户可随时要求修改，单片要求优先且不自动覆盖长期标准。字体必须在用户电脑存在，缺字时核对回退；本包不附音乐，无曲库时询问用户提供或明确选择无配乐。

制作新工程时把已确认的字体写入 story.fontFamily，把字幕、速度、BGM和音效规则落实到相应工程/混音参数，不能只保存设置就宣称已应用。旧工程按原参数复现，除非用户要求应用新标准。字体/音频等不可由当前模板参数直接表达时先适配和验证，不冒充已生效。

首次工作台未安装时，可在本地执行授权范围内运行安装入口；无交互安装被“未确认标准”阻止时，先向用户呈现选择，再保存标准重试，不静默越过。

## 实际入口

在工作台根目录执行：

```sh
node scripts/studio-cli.mjs env-check
node scripts/studio-cli.mjs list-templates --json
node scripts/studio-cli.mjs read-spec team.scene-narration --version 0.2.1-native --json
```

第三条仅为模板查询示例，实际按用户题材选择。当前CLI仅提供只读检查与目录/规范/工程读取，不存在“一键自动制作”命令。使用现有素材、草稿、生成与导出接口时，先读对应脚本，不猜测接口参数；完整原生工程导出使用scripts/render-studio-project.mjs。通过STUDIO_ORIGIN指定本次运行地址。

需要安装时读取工作台的 docs/安装升级与配置.md。缺少依赖先报告并在授权范围安装；不要调用作者的Python路径、凭证或付费账号。选定模板后固定版本和输入指纹。学习参考不可当作可直接导出的原生模板。

## 执行

1. 接收视频/音频、字幕、发布方向和本次要求，检查素材版本。
2. 分析论点、证据、转折、结论，组织七列导演表。时间锚点来自真实声音；缺对齐时只做语义草案。
3. 用户要求先出方案时，交付方案并等待确认；已有有效授权不重复询问。AI预算必须在提交前明确。
4. 用模板布局和动作组织本期内容；模板有写死文案时先参数化或局部修改，不残留旧题材。原生渲染能力不足时明确说明所需扩展，不偷偷改用另一套产品。
5. 先检查开场、最长文字、密集关系图、人物窗口过渡、AI衔接和结尾；修改后导出正式版本。
6. 检查最终编码视频的声画、内容和规格。交付视频、可编辑工程、素材绑定、字幕、质检和来源记录；按需求附封面、发布文案。程序通过不等于用户审片通过。

任务目录留存输入检查、分镜、字幕取舍、时间映射、素材来源、AI任务与报价、导出任务及质检记录；不得夹带密钥。修订从已有工程继续，保留旧版，不重复购买已有AI素材。

## 0.2.2图解分层与圆窗

用户要求图解加人物或提升渲染效率时，读取[分层渲染与圆窗](references/分层渲染与圆窗.md)。分层导出可使用 --pipeline=layered-v1；仅单图层竖屏无露脸motionVersion=2支持，其他范围自动回退。人物裁切和分段映射必须来自实际素材。先保存工程，再导出；缓存只在单次导出内复用。

## 分发与接入

本技能适配具备本地文件和命令执行权限的 WorkBuddy、Codex 等助手。首次调用先由用户提供已安装工作台目录；缺失时指导下载同版本工作台包并运行安装入口，不把技能安装视作运行环境就绪。不自动修改客户端配置。通用制作入口为场景叙事口播、暖纸数字口播、知识付费讲解；研究规范不是可直接出片模板。

创建或更新自己的模板时读取工作台 docs/模板开发与迭代.md。使用新ID与版本，先检查和预览再标记production；不覆盖内置模板，不把用户草稿或原片当可发布模板。
