# 制作模板

发行版仅包含三个制作入口：场景叙事口播 0.2.1-native、暖纸数字口播 0.1.0、知识付费讲解 0.2.2。统一目录由 scripts/template-catalog.mjs 生成。

本地学习研究库与发行包独立；本包不包含学习模板、研究报告、参考原片或候选版本。底层兼容代码保留以支持旧工程，但不是公开模板目录。

## 通用制作规范

每片使用一个统一主题。字幕按语义短句单行展示、去尾标点，突出关键词；时间来自实际声音与明确的变速映射。人物、图解和字幕各有安全区。真实截图、品牌与数字由用户提供可核验材料，不生成伪证据。配乐使用用户自己的曲库；可选付费生成需要预算授权。

场景叙事用于真人与证据、流程关系；暖纸用于数据和商业解读；知识付费讲解用于整屏方法图解，可选人物圆窗。知识付费讲解的新题材优先使用已参数化的 focus/problems/barrier/consequences/toolbox/pareto/deconstruct/summary；其他旧语义图解不作为本次通用入口，需要另行适配。

同片不交替深浅底色。新内容需要重新组织文案、素材和声音锚点，模板不是任意口播一键无需校对出片。技术检查与用户审片分别记录。发行包模板的适用范围与限制见各版本 manifest.json 和 controls.json。
