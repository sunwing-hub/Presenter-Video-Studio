# 安装、升级与配置

## 安装

完整解压并准备 Node.js >=22.18。在工作台目录运行 `npm run setup`，安装锁定依赖、Chromium，构建并检查环境。macOS/Windows 提供双击入口。运行 `npm start` 保留服务窗口，关闭时 Ctrl+C。

可运行 `npm run doctor` 检查依赖。首次安装需要联网；Python/Whisper 是可选字幕识别能力，不属于仅导入 SRT 的必要依赖。透明 MOV 目前依赖 macOS 与 Apple Command Line Tools；Windows/Linux 不承诺该功能。

## 升级

停止旧工作台和导出任务，备份完整旧目录；新版本解压到独立目录并先完成安装检查。需要保留旧工程时，将旧目录的 media、drafts、exports、user-data、user-templates 在服务停止时复制到新目录相应位置，保留所有文件与编号。不要覆盖新源码、模板或锁文件。用户自己的输出与配置另行保留，密钥不要上传 GitHub。确认新工程能打开后再停用旧目录，旧备份可用于恢复。

本发行包不自动执行旧目录迁移，不主动删除旧数据。已启动旧服务时，新目录使用不同端口，以免连接旧实例；环境变量 OVERLAY_STUDIO_PORT 控制启动端口，STUDIO_ORIGIN 控制导出脚本连接地址。

## 素材与配乐

导入自己的视频、SRT、图像与音乐。配乐库路径由每个用户提供，不能沿用原作者路径。模板提供表达结构，品牌 Logo、真实界面、数字与来源需要逐片提供和核对。不要把参考事实当作新视频内容。

## 可选 AI 服务

生成服务为可选，不影响本地基础编排。按所选服务的文档配置用户自己的凭证，确认预算后提交；不自动购买或付费重试。没有凭证时应使用自有素材或明确的示意图。

## 首次制作标准

安装器首次会询问默认或自定；无交互的AI安装必须先询问用户，再通过 preferences.mjs defaults/custom 保存，不会静默代选。首次打开工作台同样提供设置页面；已保存后不反复询问，可点击“制作标准设置”修改。user-data/preferences.json 只保存在用户电脑，不上传GitHub。
