# 模板演示与画廊

## 查看

启动本机工作台，访问 `/?templateLab`。首页以实际竖屏渲染帧展示三个模板；悬停静音播放，打开详情后可使用播放器与四个章节入口。尊重系统减少动画偏好，同一时间仅一个卡片预览播放。手机使用单列画廊。

点击“使用此模板创建工程”，工作台会复制公开的通用演示素材，建立新的独立草稿并绑定所选模板版本。标题、标签和暖纸参数可在原生编辑器修改；将示意人物、静音时钟、示例文案替换为自己的口播与素材后，重新核对时间再导出。不会覆盖已有工程。

## 演示来源

三个16秒视频全部由本工作台原生工程渲染器导出，25fps、1080×1920。人物为原创代码插画，资料为通用演示图，不代表真人或真实业务案例。演示无口播、无配乐；不是作者私人作品或学习原片。海报取自实际导出视频。

- 场景叙事：人物开场、关系流程、证据画面、观点收束。
- 暖纸数字：数字错峰、步骤展开、双列对比、结论卡片。
- 知识付费：观点聚焦、步骤拆解、层级递进、总结收束。

## 资源和重建

`public/template-demos/` 保存允许分发的SVG、PNG、源示意视频、演示MP4、海报及portable starter.json。starter中的旧UUID仅作可移植绑定键；创建时重新导入为本机素材编号，不需要作者的media目录。

运行 `STUDIO_ORIGIN=http://127.0.0.1:实际端口 node scripts/build-template-showcases.mjs` 可复用已有演示、更新海报；加 `--force` 可重新通过原生导出队列渲染全部演示。脚本不会自行启动另一个渲染引擎。首次重建源插画需先将SVG转为同名PNG，并准备对应示意源视频与静音时钟；这些公开资源已随仓库提供。创建者修改镜头或代码后应force重建并复核。

原生导出任务、绝对路径和审阅记录只保留在被忽略的output、exports目录，不能复制到public。资源变更后重建模板catalog并运行测试。自建模板若希望使用创建按钮，应提供与自身ID/版本一致的starterProject，而不是冒用另一个模板的工程。

## 核验

- 三个可移植工程均通过原生导出格式检查；资源路径限制在template-demos目录内。
- 浏览器已验证三个模板独立创建、素材重新绑定、四镜画面与文本边界，以及创建按钮实际导航。
- 桌面/手机布局无横向溢出；播放器章节跳转、Esc关闭、焦点回到触发按钮可用。
- 本地个人Skill、曲库、默认提速规则与学习研究库未改动。
