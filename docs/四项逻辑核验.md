# 四项逻辑核验：2026.11.5-r2

## 1. 发行包隐私

从GitHub下载实际v2026.11.5完整包，扫描已知作者本机路径、主机邮箱及常见密钥格式，未命中。附件不含media/drafts/exports/output、Git目录或依赖链接，不含研究原片和拆解报告。公开仓库账号、代码版权与第三方许可署名保留，不把它们称为已匿名化。

r2使用可重复打包脚本排除user-data、user-templates、私人素材和凭证，并生成文件清单和SHA-256。扫描不能证明所有未知个人信息绝对不存在；本次结论限于检查的文件与规则。GitHub提交本身有作者元数据，与下载ZIP中的私人制作资料不同。

## 2. 安装与用户模板

同一个本地Node安装器供Codex、WorkBuddy等能执行本地命令的助手使用；独立Skill符合SKILL.md结构并提供导入说明。Web-only远程环境不能直接访问用户电脑。没有宣称所有WorkBuddy版本均已实机验收。

使用三个内置制作模板，或由助手调用create-user-template建立独立模板草稿。浏览器实测development草稿隐藏，production制作版本进入动态模板中心。自建模板基于已有渲染器；新布局仍需写实际渲染代码并验证。

本机独立全新目录运行安装器通过：依赖安装、FFmpeg下载、构建、FFmpeg/Chromium与macOS编译工具检查成功。使用测试用默认确认和本机下载缓存，不修改作者现有工作台；这不等于Windows/Linux或所有客户端实机验收。

## 3. 持续发布

作者研究库与发行仓库独立，仅production模板打包；新ID/版本、manifest、controls、渲染实现与验证记录一起更新。目录生成器支持内置templates和本机user-templates；用户设置和自建模板不会因安装器生成目录而被覆盖。升级迁移方式、兼容边界及打包脚本已提供。

## 4. 默认或自定

安装器首次询问默认[d]或自定[c]；非交互调用没有标准时停止并要求助手先问用户，不静默代选。首次网页提供明确确认。Skill首次读取status，必须等用户选择后保存；后续读取已保存标准，不重复问。

默认：系统中文无衬线字体、单行语义字幕、自己的BGM库、稀疏代码音效、-16 LUFS/-1 dBTP参考目标、原速。没有曲库时询问或明确选择无配乐。标准写入本机user-data/preferences.json，用户可修改。用户新要求优先，旧工程不自动重做。

单元测试与浏览器检查验证了默认/自定、持久化、刷新后不重复、修改、草稿隐藏和制作模板发现。新工程由Skill读取标准并落实到字体、字幕、速度和混音；保存配置不等于自动重渲染已有工程。
